# LightCull
> *Aplikasi untuk mensortir foto secara otomatis; terutama menghapus foto yang terlalu terang (overexposed) dan terlalu gelap (underexposed).*

Funfact! The "Light" in LightCull serves 2 meaning, light - as in lightweight; and light - as in exposure values.

*Repo ini adalah versi spesial demi menyelesaikan Tugas Akhir (TA) Praktikum Pemrograman Dasar*
